Acme Widget Pro documentation

How do I set up the Acme Widget Pro?

Unbox the widget, fit the housing clips until they click, and run the self-test from the side button. The test takes about a minute and confirms the motor, the sensor and the battery contacts before first use.

How often does it need maintenance?

Clean the housing every week of use and replace the filter every three months. The widget logs its own hours, so the maintenance reminder on the display is a better guide than the calendar for busy workshops.

  • Weekly cleaning
  • Quarterly filter
  • Yearly service
